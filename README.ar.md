# Navidrome Wrapped

ملخص سنوي لـ Navidrome بأسلوب Wrapped: الفنانون والمقطوعات الأكثر استماعًا، دقائق الاستماع، الاكتشافات، وإحصاءات مثل الاستماع ليلًا والتكرار والساعة المفضلة. يعرض مشغل القصص موسيقى في الخلفية، ويمكن حفظ كل بطاقة بصيغة PNG.

- **الخادم:** FastAPI وSQLite للقراءة فقط وffmpeg للمقاطع الصوتية.
- **الواجهة:** HTML وCSS وJavaScript مع Swiper، دون حاجة إلى بناء أو CDN.
- **السمات:** يمكن تخصيص المظهر والنصوص وترتيب الشرائح. راجع [THEMES.md](THEMES.md).
- **اللغات:** الإنجليزية والألمانية والإسبانية والروسية والصينية واليابانية والكورية والعربية.
- **إمكانية الوصول:** إيقاف مؤقت بلوحة المفاتيح، ومؤشر تركيز واضح، وإعلانات للشرائح لقارئات الشاشة. لم يُجرَ تدقيق رسمي ولا نضمن التوافق مع WCAG.

## النشر

يعمل التطبيق داخل حاوية Linux. يتطلب Windows ‏64 بت Docker Desktop وWSL 2. لا يتوفر إصدار أصلي لـ Windows ولا دعم لـ Windows ‏32 بت.

```bash
cp .env.example .env
./deploy.sh
# → http://عنوان-الخادم:8100/
```

أهم إعدادات `.env`:

| المتغير | الإعداد |
|---|---|
| `NAVIDROME_NETWORK` | شبكة Docker الخاصة بـ Navidrome |
| `NAVIDROME_DATA_DIR` | مجلد المضيف الذي يحتوي على `navidrome.db` |
| `MUSIC_DIR_HOST` | مجلد الموسيقى على المضيف |
| `WRAPPED_LANGUAGE` | `en` (افتراضي) أو `de` أو `es` أو `pt` أو `fr` أو `ru` أو `zh` أو `ja` أو `ko` أو `ar` |
| `ADMIN_KEY` | مفتاح استيراد السمات بصيغة ZIP |
| `PUID` / `PGID` | معرف المستخدم/المجموعة اللذين يمكنهما قراءة المجلدات |

يجب تركيب الموسيقى داخل الحاوية في المسار نفسه الذي يستخدمه Navidrome (غالبًا `/music`). بعد تغيير `WRAPPED_LANGUAGE` شغّل `./deploy.sh` مجددًا. تحتاج السمات المخصصة إلى ترجمات خاصة بها. يمكن لكل زائر تغيير اللغة من القائمة أعلى اليمين؛ ويُحفظ الاختيار في متصفحه ولا يغيّر اللغة الافتراضية للخادم.

## الاستخدام والأمان

أدخل اسم مستخدم Navidrome واختر السنة في شاشة البداية. ركّز على منطقة القصة واستخدم ←/→ للتنقل. يمكن الإيقاف المؤقت بالزر أو بالمفتاح `P`. تحترم الواجهة إعداد النظام لتقليل الحركة.

تسجيل الدخول معطّل افتراضيًا. عند إتاحة التطبيق خارج الشبكة المنزلية، استخدم وكيلًا عكسيًا عبر HTTPS مع مصادقة. قد تشغّل السمات JavaScript في المتصفح؛ استورد السمات الموثوقة فقط.

## API والتطوير

المسارات الرئيسية: `/api/health` و`/api/config` و`/api/years?user=` و`/api/wrapped?user=&year=` و`/api/themes` و`/api/themes/{id}`. لمزيد من التفاصيل عن السمات والعرض التجريبي المحلي، راجع [README بالإنجليزية](README.md) و[THEMES.md](THEMES.md).
