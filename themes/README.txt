Tus temas van aquí (esta carpeta se monta en /themes dentro del contenedor).
Cada tema es una carpeta con un theme.json:  themes/2027/theme.json

  python scripts/theme.py new 2027          # crea un tema nuevo
  python scripts/theme.py install tema.zip  # importa un tema empaquetado

Un tema tuyo con el mismo id que uno incluido (classic, neon) lo sustituye.
Guía completa: THEMES.md
